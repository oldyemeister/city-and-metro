## Method and limits

`analyze.py` uses Python stdlib only. Profiles keyed by PID/profile ID (ProfileChunk TID belongs to profiling helper, not sampled worker). Reconstruct cumulative timestamps from Profile.startTime plus signed timeDeltas; sort samples chronologically before assigning each sample duration until next sample; clip to selected window. Negative deltas occur (10,809 main samples), so blindly clipping negative deltas inflates totals and is invalid. First pre-sample interval and final unsampled tail omitted. Function self/inclusive values are elapsed statistical estimates, not thread CPU counters. Different workers begin profiling at different times (+4.77…8.34s), and recording/profiler startup adds overhead. Cross-check road hotspot with independent FunctionCall durations. No claim that recording duration equals exact two-month completion time, or that sampled time equals an unprofiled baseline.
