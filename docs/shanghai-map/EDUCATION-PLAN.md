估算依据与限制：

- 江湾以 2008 法学院、2017—2020 理科迁入、2019 的 3200 人、近期约 1.2 万人构成锚点；中间区间仅为量级提案。2005 的小规模使用人数缺少直接证据。
- 张江以一期/二期和有限院系规模推估数千人，未找到可靠的全校区人数序列；不依据占地面积直接换算学生数。
- 邯郸与枫林缺少同口径逐年校区人数；上述区间仅供比较主次，不能当正式数据写进史实说明。并校前后全校人数的统计范围也不同。
- 校区迁移和扩招同时存在：不能机械要求邯郸绝对人数持续下降，也不能把新校区学生全部当作全市新增学生。
- 不把跨校区上课的同一个学生累计成多个独立在校生。短期培训、非全日制和附属医院实习分布另算。
- 上海场景当前 `histEnd:2020`，之后是模拟未来；近期 1.2 万人只能作为情景量级参考，本批默认不把 2021—2026 的实际发展硬编码成历史保证。

## 待加入的数据行为（尚未写入游戏）

1. 邯郸保留设施和地标现有 ID，明确校区名，不因搬迁停用整个校区。
2. 江湾、张江使用各自稳定新 ID 和 `t:'uni'`（既有 `sc` 上学目的），不新增模拟算法。
3. 启用时间先以 2005 年秋为讨论方案；江湾 2008、2017—2020、张江 2008 为主要变化节点，日期精度以证据为准。
4. 用现有 `w:[[year,value],…]` 表达需求吸引权重；现有插值可能提前渐变，实施时区分渐增与在特定月份迁入，不把竣工日误作所有学生入驻日。
5. 人数不直接填入 `w` 或 `pax`。`Fac.share` 将 `w` 乘 `facBoost`，模拟还有各目的设施总量上限；需在所有教育设施候选明确后统一估权重。旧 `0.035` 仅作兼容和平衡参照，尚无已批准的新权重。
6. 不假设校内住宿学生每天乘地铁通学；当前模型抽象和周末系数先沿用，人数只辅助分配，不宣称新增了真实的大学出行模型。
7. 枫林是否加入第一批、医学生暂迁是否值得表达，留待用户讨论。避免与医院的就医需求混成同一设施。
8. 实施前检查坐标系、校园范围、道路可达性、用地启用、存档兼容；不挪动既有设施 ID，不改事件顺序。实施后再运行构建和针对性检查。
